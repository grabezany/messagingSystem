# Conversational AI SMS Bot

This Node.js application creates a conversational AI chatbot that responds to standard SMS text messages (green bubbles) on your phone. It connects a **Twilio** virtual number to **Google Gemini AI** and is optimized for zero-configuration deployments on **Render**.

## Deployment Instructions

1. Push all these files (excluding `node_modules/`) to a private or public GitHub repository.
2. Log into your Render dashboard and create a new **Web Service**.
3. Link your GitHub repository.
4. Set your configuration properties:
   - **Runtime:** `Node`
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
5. Under **Environment Variables**, add:
   - Key: `GEMINI_API_KEY` | Value: *[Your secret Google Gemini API key]*
6. Copy the resulting Live URL generated by Render, add `/sms-webhook` to the end, and paste it into your Twilio Sandbox Console under your number's active **Messaging Webhook** settings.
